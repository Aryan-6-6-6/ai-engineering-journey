# Data Science & Machine Learning Portfolio

This repository serves as a comprehensive documentation of my practical experience in data science, featuring implementations of various algorithms across different domains. 

## 📂 Repository Structure

The project is divided into two primary sources:

### 1. [Kaggle](./Kaggle)
Contains notebooks and datasets sourced from Kaggle, covering:
*   **Regression:** Linear models, house price predictions, and baseline architectures.
*   **Classification:** Supervised learning for categorical data, binary, and multi-class problems.
*   **Unsupervised Learning:** Pattern discovery through clustering and dimensionality reduction.
*   **Deep Learning:** Advanced neural networks built using TensorFlow and PyTorch.
*   **NLP:** Natural Language Processing, text mining, and sentiment analysis.
*   **OpenCV:** Computer vision pipelines and image processing techniques.

### 2. [UCI ML Repository](./UCI%20ML%20Repository)
Contains classic machine learning problems from the UCI archive:
*   **Regression**
*   **Classification**
*   **Clustering**

## 📈 Growth Timeline & Project Evolution
> **Note on Repository Maturity:**
> This repository documents my end-to-end learning journey from day one. Some of the initial baseline notebooks—particularly in the early **Regression** folders—are left in their original, raw, and unstructured format. 
> 
> While these early files could be refactored to match my current standards, they are deliberately kept **untouched** to serve as an objective benchmark. This allows viewers to evaluate my historical baseline against my modern, professional workflows, demonstrating my evolution in clean coding, modular structure, and engineering principles over time.

## 🛠️ How it's Organized
Inside each sub-folder (e.g., `Kaggle/1. Regression/Project_Name`), you will find:
1.  **Jupyter Notebook (.ipynb):** The complete code, explanatory markdown, and analysis.
2.  **Dataset Asset:** A local copy of the raw data used for seamless replication.
3.  **Project README:** A specific technical breakdown detailing the goals, libraries used, and model performance metrics.
4.  **Source Links:** Every notebook includes a direct hyperlink to the original dataset on Kaggle or UCI for verification and deeper exploration.

---
**Core Objective:** To document an evolving learning journey while providing a reproducible, structured reference for common machine learning and deep learning workflows.
