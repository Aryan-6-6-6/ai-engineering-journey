# ❤️ Heart Disease Prediction Using Machine Learning

## 📖 Overview

This project predicts the presence of **heart disease** using multiple Machine Learning classification algorithms. It follows a complete Machine Learning workflow, including data cleaning, exploratory data analysis (EDA), preprocessing, hyperparameter tuning using **GridSearchCV**, and model comparison to identify the best-performing classifier.

**📓 Kaggle Notebook:**
https://www.kaggle.com/code/abacilla/heart-csv

---

# 📊 Dataset

The project uses the **Heart Disease Dataset**, which contains patient health information such as age, sex, chest pain type, blood pressure, cholesterol level, fasting blood sugar, ECG results, maximum heart rate, exercise-induced angina, and other clinical attributes.

The objective is to predict whether a patient is likely to have **heart disease** based on these medical characteristics.

**🎯 Target Variable:** `Heart Disease`

**📂 Dataset:**
https://www.kaggle.com/code/abacilla/heart-csv

---

# 🔍 Exploratory Data Analysis (EDA)

A comprehensive Exploratory Data Analysis (EDA) was performed to understand the dataset, identify data quality issues, and discover relationships between patient characteristics and heart disease.

### Analysis Performed

* Dataset overview and descriptive statistics
* Missing value analysis
* Duplicate record detection
* Univariate analysis
* Distribution analysis of numerical features
* Correlation heatmap
* Outlier analysis
* Relationship analysis between clinical features and the target variable

### 📌 Key EDA Insights

* The dataset was clean with minimal preprocessing requirements.
* Several clinical features showed a strong relationship with heart disease occurrence.
* Correlation analysis helped identify influential medical attributes for prediction.
* The dataset was suitable for evaluating multiple classification algorithms.

---

# ⚙️ Data Transformation & Preprocessing

Based on the EDA findings, the following preprocessing steps were performed:

* Removed duplicate records (if present)
* Encoded categorical variables where required
* Applied feature scaling
* Split the dataset into training and testing sets
* Optimized hyperparameters using **GridSearchCV**
* Evaluated models using **5-Fold Cross Validation**

# 🏆 Results

Six classification models were optimized using **GridSearchCV** and compared using the **Cross-Validation Accuracy**.

| Rank | Model                               | Best CV Score |
| :--: | ----------------------------------- | :-----------: |
|  🥇  | **Logistic Regression**             |   **0.8389**  |
|  🥇  | **Support Vector Classifier (SVC)** |   **0.8389**  |
|  🥉  | Random Forest Classifier            |   **0.7977**  |
|   4  | XGBoost Classifier                  |   **0.7976**  |
|   5  | K-Nearest Neighbors (KNN)           |   **0.7936**  |
|   6  | Decision Tree Classifier            |   **0.7188**  |

### 🏅 Best Model Performance

The **Logistic Regression** model achieved the best overall performance.

| Metric            |      Value |
| ----------------- | ---------: |
| **Test Accuracy** | **83.61%** |

### 🔍 Key Findings

* 🥇 **Logistic Regression** achieved the highest Cross-Validation score (**0.8389**) and the best overall performance.
* 🤝 **Support Vector Classifier (SVC)** achieved the same Cross-Validation score, demonstrating comparable performance.
* 🌲 Ensemble models such as **Random Forest** and **XGBoost** also performed competitively.
* 📈 Hyperparameter tuning using **GridSearchCV** improved model selection and performance.
* ❤️ Comparing multiple classifiers provided a better understanding of which algorithms are most suitable for heart disease prediction.
