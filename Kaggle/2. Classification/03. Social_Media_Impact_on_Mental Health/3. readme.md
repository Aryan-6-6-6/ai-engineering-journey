# 📱 Social Media Impact on Teen Mental Health — Depression Prediction

## Overview

This project predicts **depression risk** in teenagers based on social media usage, sleep, academic, and lifestyle factors. It covers EDA, preprocessing, and comparison of multiple classification models tuned with GridSearchCV.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/social-media-impact-on-mental-health

---

## Dataset

Teen mental health survey data covering social media habits, sleep, stress, anxiety, and addiction levels.

* **Target:** `depression_label` (0/1)
* **Dataset:** https://www.kaggle.com/datasets/sunil123kumar/social-media-impact-on-mental-health

---

## 🔍 EDA

* Checked shape, dtypes, stats, nulls, duplicates, and unique value counts
* No missing values, no duplicates
* Univariate: histograms/pie charts for age, social media hours, platform usage, sleep, screen time, activity, stress, anxiety, addiction, and depression label
* Bivariate: boxplot (social media hours vs depression), regplots (sleep vs stress, bedtime scroll vs sleep), barplot (addiction by platform)
* Multivariate: scatter plot (social media vs sleep, colored by depression), full correlation heatmap

### 📌 Key Insights

* Dataset is balanced across age (13–19) and gender; platform usage is evenly distributed
* **`depression_label` is highly imbalanced** — only ~2.6% positive cases
* Sleep hours and stress level show a weak negative relationship
* Bedtime scrolling and sleep hours show a weak positive relationship
* No strong linear correlations among numeric features overall

---

## 🛠️ Data Preprocessing

* Renamed columns for readability (`screen_time_before_sleep` → `bedtime_scroll`, `physical_activity` → `activity_hrs`)
* Rounded float columns and lowercased text columns for consistency
* One-hot encoded categorical columns (`gender`, `platform_usage`, `social_interaction_level`)
* Train-test split (80/20, `random_state=42`)
* Standardized non-binary numeric features using `StandardScaler` (fit on train, transformed on test)

---

## 🤖 Model Selection & Tuning

* 5-fold cross-validation (`KFold`, shuffled, `random_state=42`)
* **GridSearchCV** used to tune 4 models:

| Model | Best Params | Best CV Accuracy |
| :--- | :--- | :---: |
| Decision Tree | `max_depth=None, min_samples_split=2` | **0.9969** |
| SVM | `C=10, gamma='scale', kernel='rbf'` | 0.9896 |
| Logistic Regression | `C=1, solver='liblinear'` | 0.9823 |
| KNN | `n_neighbors=5, weights='uniform'` | 0.9781 |

**Best Model: Decision Tree**

---

## 🏆 Results

Test set performance of the best model (Decision Tree):

* **Accuracy:** 0.9917
* **Class 0 (no depression):** Precision 1.00, Recall 1.00, F1 1.00
* **Class 1 (depression):** Precision 0.83, Recall 0.83, F1 0.83

### 📌 Key Findings

* Despite ~99% overall accuracy, the dataset is **highly imbalanced**, so accuracy alone is misleading
* The model performs near-perfectly on the majority class but is **less stable on the minority (depression) class** due to limited samples
* Tree-based models outperformed linear and distance-based models on this dataset
