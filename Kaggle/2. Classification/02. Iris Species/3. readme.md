# 🌸 Iris Species Classification using K-Nearest Neighbors (From Scratch)

## Overview

This project classifies iris flowers into **Setosa**, **Versicolor**, or **Virginica** based on sepal and petal measurements, using a **K-Nearest Neighbors classifier implemented from scratch**.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/iris-species

---

## Dataset

The classic **Iris Dataset** — sepal and petal measurements for 3 species.

* **Target:** `Species`
* **Dataset:** https://www.kaggle.com/datasets/uciml/iris

---

## 🔍 EDA

* Checked shape, dtypes, and stats (`.info()`, `.describe()`)
* Count plot, correlation heatmap, and pairplot (hue = Species)

### 📌 Key Insights

* No missing values, no duplicates
* Perfectly balanced classes (50 each)
* Petal Length/Width clearly separate the species, especially Setosa

---

## 🛠️ Preprocessing

* Dropped `Id` column
* Label-encoded `Species` → 1/2/3
* Train-test split (75/25, `random_state=42`)
* Manual z-score scaling (train mean/std applied to test set)

---

## 🤖 Model

* **KNN from scratch** — Euclidean distance, **k = 5**, majority voting

---

## 🏆 Results

| Metric | Score |
| :--- | :---: |
| Accuracy | **1.00** |

### 📌 Key Findings

* Perfect accuracy — consistent with EDA showing well-separated classes
* Iris is a small, balanced, easily separable dataset, so this result is expected
