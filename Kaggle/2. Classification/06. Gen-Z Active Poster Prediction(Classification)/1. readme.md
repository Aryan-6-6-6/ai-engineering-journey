# 📱 Gen Z Active Poster Prediction using Machine Learning

## 📖 Overview

This project predicts whether a Gen Z user is an **active social media poster** using supervised Machine Learning. The workflow includes exploratory data analysis (EDA), data preprocessing, feature engineering, model training, hyperparameter tuning, and model evaluation to identify the most effective classification model.

Multiple Machine Learning algorithms were trained and compared using **RandomizedSearchCV** with cross-validation. Their performances were evaluated using classification metrics, enabling a fair comparison between linear and tree-based models.

📓 **Kaggle Notebook:**  
https://www.kaggle.com/code/abacilla/gen-z-active-poster-prediction-classification

---

## 📊 Dataset

The dataset contains information about Gen Z users, their social media usage patterns, engagement behavior, and demographic attributes. The objective is to classify whether a user is an **active poster** based on these characteristics.

**Target Variable**

- **Active Poster**
