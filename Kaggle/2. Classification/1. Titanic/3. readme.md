# Titanic Survival Prediction Using Machine Learning

## Overview

This project predicts whether a passenger survived the Titanic disaster using multiple Machine Learning classification models. It covers the complete machine learning pipeline, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and model comparison to identify the best-performing classifier.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/titanic-dataset

---

## Dataset

The project uses the **Titanic Dataset**, which contains passenger information such as age, gender, passenger class, fare, family size, embarkation details, and survival status.

**📊 Dataset:** https://www.kaggle.com/code/abacilla/titanic-dataset

## 🏆 Results

Seven Machine Learning classification models were trained and evaluated using **Accuracy Score**.

| Rank | Model                  |  Accuracy  |
| :--: | ---------------------- | :--------: |
|  🥇  | Logistic Regression    | **82.12%** |
|  🥇  | XGBoost                | **82.12%** |
|  🥇  | Gradient Boosting      | **82.12%** |
|   4  | Support Vector Machine |   81.56%   |
|   5  | Random Forest          |   81.01%   |
|   6  | K-Neighbors Classifier |   79.89%   |
|   7  | Decision Tree          |   78.77%   |

### Key Findings

* **Logistic Regression**, **XGBoost**, and **Gradient Boosting** achieved the highest accuracy of **82.12%**, making them the top-performing models.
* **Support Vector Machine** also delivered competitive performance with an accuracy of **81.56%**.
* Comparing multiple algorithms helped identify the most suitable model for the Titanic survival prediction task.
