# 🍔 Online Food Ordering Prediction using Machine Learning

## 📖 Overview

This project predicts whether a customer is likely to order food online using the **Online Food Dataset**. The workflow includes data understanding, exploratory data analysis (EDA), preprocessing, feature engineering, model training, hyperparameter tuning, and model evaluation.

Multiple classification algorithms were trained and compared to identify the most accurate model. Hyperparameter tuning was performed using **RandomizedSearchCV** with cross-validation, and the final models were evaluated using classification metrics including Accuracy, Precision, Recall, and F1-Score.

📓 **Kaggle Notebook:**  
https://www.kaggle.com/code/abacilla/online-food-dataset-classalgo#5.-Machine-Learning-and-Hyperparameter-Tuning

---

## 📊 Dataset

The Online Food Dataset contains customer demographic information, occupation, income, education, location, and feedback details to predict whether a customer is likely to place an online food order.

- **Dataset Size:** 388 records
- **Target Variable:** Output (Online Food Order: Yes/No)

> **Note:** The dataset is too large to upload to GitHub, so only the Kaggle dataset link is provided.

📂 **Dataset:**

## 🔍 Exploratory Data Analysis (EDA)

The notebook performs exploratory data analysis to understand customer demographics, identify data quality issues, and discover patterns before model development.

### Analysis Performed

- Dataset overview and structure inspection
- Shape and feature analysis
- Missing value analysis
- Duplicate record detection
- Data type inspection
- Descriptive statistical analysis
- Unique value and spelling consistency checks
- Numerical feature distribution analysis
- Categorical feature analysis
- Correlation heatmap
- Pairplot visualization
- Count plots and distribution plots
- Relationship analysis between customer attributes and online ordering behavior

### 📌 Key EDA Insights

- The dataset contains **388 customer records** with both numerical and categorical features.
- No missing values were present, but duplicate records were identified.
- Customer demographics such as occupation, income, and education showed noticeable variation.
- Correlation analysis helped identify relationships among numerical variables.
- Customer feedback and demographic attributes contributed useful information for classification.

## ⚙️ Data Transformation & Preprocessing
