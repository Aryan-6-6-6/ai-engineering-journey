# Salary Prediction Using Linear Regression

## Overview

This project focuses on predicting employee salaries based on years of professional experience using Machine Learning techniques. The dataset demonstrates the relationship between work experience and salary, making it an excellent beginner-friendly regression problem. The primary objective is to analyze how experience influences salary growth and build a Linear Regression model capable of estimating salaries accurately.

## Dataset

The dataset contains employee salary information with the following features:

| Feature         | Description                                |
| --------------- | ------------------------------------------ |
| YearsExperience | Number of years of professional experience |
| Salary          | Annual salary (Target Variable)            |

The dataset is commonly used for learning and implementing Simple Linear Regression models.

## Key Insights

* Salary generally increases with years of experience.
* A positive linear relationship exists between experience and salary.
* Linear Regression effectively captures the trend in the dataset.
* Experience is a strong predictor of salary in this dataset.
