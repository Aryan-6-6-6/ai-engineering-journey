# 🤖 Impact of AI on Students Using Machine Learning

## 📖 Overview

This project predicts the **Impact of AI on Students** using multiple Machine Learning regression models. It follows a complete end-to-end Machine Learning workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, data preprocessing, hyperparameter tuning using **RandomizedSearchCV**, and model comparison to identify the best-performing regression model.

**📓 Kaggle Notebook:**  
https://www.kaggle.com/code/abacilla/impact-of-ai-on-students#1.-Understanding-Data

---

# 📊 Dataset

The project uses the **Impact of AI on Students Dataset**, which contains student-related academic, behavioral, and AI usage features to analyze how Artificial Intelligence influences student performance and learning.

The objective is to predict the **AI Impact Score** using various student-related attributes.

**🎯 Target Variable:** `AI Impact Score`

**📂 Dataset:**  
https://www.kaggle.com/code/abacilla/impact-of-ai-on-students#1.-Understanding-Data

# 🔍 Exploratory Data Analysis (EDA)

A comprehensive Exploratory Data Analysis (EDA) was performed to understand the dataset, identify data quality issues, and uncover meaningful relationships before model development.

### Analysis Performed

- Dataset overview and descriptive statistics
- Missing value analysis
- Duplicate record detection
- Univariate analysis
- Distribution analysis of numerical and categorical features
- Correlation heatmap
- Outlier detection
- Relationship analysis between AI-related factors and the target variable

### 📌 Key EDA Insights

- The dataset contained a mix of numerical and categorical features requiring preprocessing.
- Correlation analysis helped identify the most influential variables affecting the AI Impact Score.
- Outlier detection improved data quality before model training.
- EDA provided valuable insights for feature engineering and model selection.

# ⚙️ Data Transformation & Preprocessing

Based on the EDA findings, the following preprocessing steps were performed:

- Removed unnecessary columns
- Handled missing values and duplicate records
- Encoded categorical variables
- Applied feature scaling
- Split the dataset into training and testing sets
- Hyperparameter tuning using **RandomizedSearchCV**
- Model evaluation using **5-Fold Cross Validation**

# 🏆 Results

Seven regression models were optimized using **RandomizedSearchCV** and compared using the **Cross-Validation R² Score**.

| Rank | Model | Best CV R² Score |
|:---:|-------------------------|:---------------:|
| 🥇 | **LightGBM Regressor** | **0.914680** |
| 🥈 | XGBoost Regressor | **0.912426** |
| 🥉 | Ridge Regression | **0.896915** |
| 4 | Linear Regression | **0.896914** |
| 5 | ElasticNet Regression | **0.896819** |
| 6 | Lasso Regression | **0.895863** |
| 7 | Decision Tree Regressor | **0.880809** |

### 🏅 Best Model Performance

The **LightGBM Regressor** achieved the best overall performance after hyperparameter tuning.

| Metric | Value |
|--------|------:|
| **MAE** | **0.1124** |
| **RMSE** | **0.1427** |
| **R² Score** | **0.9157** |

### 🔍 Key Findings

- 🥇 **LightGBM Regressor** achieved the highest **Cross-Validation R² Score (0.9147)**, making it the best-performing model.
- 🥈 **XGBoost** delivered nearly identical performance, demonstrating the effectiveness of gradient boosting algorithms.
- 📈 Hyperparameter tuning using **RandomizedSearchCV** significantly improved model performance by identifying the optimal parameters for each regression model.
- 🌳 Ensemble learning methods outperformed traditional linear regression models, capturing complex relationships within the dataset.
- 🎯 The final **R² Score of 0.9157** indicates excellent predictive performance and strong generalization on unseen data.
