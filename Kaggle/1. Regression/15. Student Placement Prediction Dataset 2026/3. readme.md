# 🎓 Student Placement Prediction Using Machine Learning

## 📖 Overview

This project predicts **student placement packages** using multiple Machine Learning regression models. It demonstrates a complete end-to-end ML workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, preprocessing, hyperparameter tuning using **RandomizedSearchCV**, and model comparison to identify the best-performing regression model.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/student-placement-prediction-dataset-2026#6.-Machine-Learning-with-Hyperparameter-Tuning

---

# 📊 Dataset

The project uses the **Student Placement Prediction Dataset 2026**, which contains academic performance, technical skills, internships, projects, certifications, and other student-related attributes to predict the **placement package**.

**📂 Dataset:** https://www.kaggle.com/datasets/sehaj1104/student-placement-prediction-dataset-2026/data

---

# 🔍 Exploratory Data Analysis (EDA)

A comprehensive EDA was performed to understand the dataset, identify data quality issues, and uncover relationships between student attributes and placement packages.

### Analysis Performed

* Histograms and Boxplots for numerical features
* Countplots for categorical features
* Univariate Analysis
* Bivariate Analysis
* Correlation Heatmap
* Missing value inspection
* Duplicate record detection
* Data type exploration
* Distribution and outlier analysis

### 📌 Key EDA Insights

* The dataset contained a mix of numerical and categorical features, requiring different preprocessing techniques.
* Numerical features exhibited varying distributions, making feature scaling important for model performance.
* Correlation analysis helped identify the features that were most influential in predicting placement packages.
* EDA guided feature transformation and preprocessing before model training.

---

# ⚙️ Data Transformation & Preprocessing

Based on the EDA findings, the following preprocessing steps were performed:

* Removed redundant columns
* Renamed columns for better readability
* Encoded categorical variables
* Applied feature scaling
* Performed Train-Test Split
* Optimized model hyperparameters using **RandomizedSearchCV**
* Evaluated models using **5-Fold Cross Validation**

# 🏆 Results

Eight regression models were trained and optimized using **RandomizedSearchCV**. Their performance was compared using the **Cross-Validation R² Score**.

| Rank | Model                 | Best CV R² Score |
| :--: | --------------------- | :--------------: |
|  🥇  | **LightGBM**          |    **0.9864**    |
|  🥈  | Random Forest         |      0.9848      |
|  🥉  | XGBoost               |      0.9792      |
|   4  | Decision Tree         |      0.9785      |
|   5  | Ridge Regression      |      0.7984      |
|   6  | Linear Regression     |      0.7984      |
|   7  | Lasso Regression      |      0.7984      |
|   8  | ElasticNet Regression |      0.7984      |

### 🏅 Best Model Performance

The **LightGBM Regressor** achieved the highest performance after hyperparameter tuning.

| Metric   |      Value |
| -------- | ---------: |
| MAE      | **0.4957** |
| RMSE     | **0.7990** |
| R² Score | **0.9859** |

### 🔍 Key Findings

* 🥇 **LightGBM** achieved the highest Cross-Validation **R² Score (0.9864)**, making it the best-performing model.
* 🌳 Ensemble tree-based models consistently outperformed traditional linear regression models.
* 📈 Hyperparameter tuning using **RandomizedSearchCV** significantly improved model performance.
* 🎯 The final LightGBM model explained approximately **98.6%** of the variance in placement packages, demonstrating excellent predictive capability.
