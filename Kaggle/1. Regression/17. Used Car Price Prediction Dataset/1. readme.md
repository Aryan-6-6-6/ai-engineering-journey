# 🏆 Results

Seven regression models were optimized using **GridSearchCV** and evaluated using the **Cross-Validation R² Score**.

| Rank | Model | Best CV R² Score |
|:---:|-------------------------|:---------------:|
| 🥇 | **XGBoost Regressor** | **0.6933** |
| 🥈 | LightGBM Regressor | **0.6931** |
| 🥉 | Decision Tree Regressor | **0.6750** |
| 4 | Ridge Regression | **0.5978** |
| 5 | Linear Regression | **0.5978** |
| 6 | ElasticNet Regression | **0.5977** |
| 7 | Lasso Regression | **0.5977** |

### 🏅 Best Model Performance

The **XGBoost Regressor** achieved the best overall performance after hyperparameter tuning.

| Metric | Value |
|--------|------:|
| **MAE** | **0.5176** |
| **RMSE** | **0.6695** |
| **R² Score** | **0.6944** |

### 🔍 Key Findings

- 🥇 **XGBoost Regressor** achieved the highest **Cross-Validation R² Score (0.6933)**, making it the best-performing model.
- 🥈 **LightGBM** delivered nearly identical performance (**0.6931**), demonstrating the effectiveness of gradient boosting algorithms.
- 🌳 Tree-based models significantly outperformed traditional linear regression models, indicating that used car prices have complex non-linear relationships.
- 📈 Hyperparameter tuning using **GridSearchCV** improved model performance by identifying the optimal parameters for each regression model.
- 🚗 Working with a dataset containing **over one million records** provided valuable hands-on experience in handling large-scale datasets and comparing multiple regression algorithms.
