# 🍫 Chocolate Sales Analysis & Boxes Shipped Prediction Using Machine Learning

## 📖 Overview

This project predicts the **number of chocolate boxes shipped** using multiple Machine Learning regression models. It follows a complete end-to-end Machine Learning workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, data preprocessing, hyperparameter tuning using **RandomizedSearchCV**, and model comparison to identify the best-performing regression model.

**📓 Kaggle Notebook:**
https://www.kaggle.com/code/abacilla/chocolate-sales-in-2022-2023

---

# 📊 Dataset

The project uses the **Chocolate Sales (2022–2023) Dataset**, which contains sales transactions along with product, salesperson, country, shipment details, and sales information.

The objective is to predict the **Boxes Shipped** based on historical sales records and related features.

**🎯 Target Variable:** `Boxes Shipped`

**📂 Dataset:**
https://www.kaggle.com/code/abacilla/chocolate-sales-in-2022-2023

# 🔍 Exploratory Data Analysis (EDA)

A comprehensive Exploratory Data Analysis (EDA) was performed to understand the sales data, identify quality issues, and uncover patterns before building the Machine Learning models.

### Analysis Performed

* Dataset overview and descriptive statistics
* Missing value analysis
* Duplicate record detection
* Univariate analysis
* Distribution analysis of numerical features
* Correlation heatmap
* Outlier analysis
* Relationship analysis between sales features and boxes shipped

### 📌 Key EDA Insights

* The dataset contained both numerical and categorical variables that required different preprocessing techniques.
* Correlation analysis highlighted the variables most closely associated with the number of boxes shipped.
* Feature distributions helped identify potential outliers before model training.
* The dataset provided sufficient variation for building accurate regression models.

# ⚙️ Data Transformation & Preprocessing

Based on the EDA findings, the following preprocessing steps were performed:

* Removed unnecessary columns
* Handled missing values and duplicate records
* Encoded categorical variables
* Applied feature scaling where required
* Split the dataset into training and testing sets
* Hyperparameter tuning using **RandomizedSearchCV**
* Model evaluation using **5-Fold Cross Validation**

# 🏆 Results

Seven regression models were optimized using **RandomizedSearchCV** and evaluated using the **Cross-Validation R² Score**.

| Rank | Model                       | Best CV R² Score |
| :--: | --------------------------- | :--------------: |
|  🥇  | **Decision Tree Regressor** |   **0.999697**   |
|  🥈  | XGBoost Regressor           |   **0.999198**   |
|  🥉  | LightGBM Regressor          |   **0.999105**   |
|   4  | Ridge Regression            |   **0.969803**   |
|   5  | Linear Regression           |   **0.969803**   |
|   6  | ElasticNet Regression       |   **0.969516**   |
|   7  | Lasso Regression            |   **0.968768**   |

### 🏅 Best Model Performance

The **Decision Tree Regressor** achieved the best overall performance after hyperparameter tuning.

| Metric       |       Value |
| ------------ | ----------: |
| **MAE**      | **0.00392** |
| **RMSE**     | **0.01101** |
| **R² Score** | **0.99978** |

### 🔍 Key Findings

* 🥇 **Decision Tree Regressor** achieved the highest **Cross-Validation R² Score (0.999697)**, making it the best-performing model.
* 🥈 **XGBoost** and **LightGBM** also achieved exceptionally high prediction accuracy, demonstrating the effectiveness of tree-based ensemble methods.
* 📈 Hyperparameter tuning using **RandomizedSearchCV** significantly improved model performance by selecting the optimal parameters for each algorithm.
* 📦 The extremely high **R² Score (0.99978)** indicates that the selected model was able to explain almost all of the variation in the target variable.
* 📊 Comparing multiple regression models provided valuable insights into how different algorithms perform on sales prediction tasks.
