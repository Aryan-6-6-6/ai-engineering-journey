# Ford Car Price Prediction

## Overview

This project focuses on predicting the selling price of used Ford cars using Machine Learning techniques. The dataset contains various vehicle attributes such as model, manufacturing year, mileage, transmission type, fuel type, engine size, and fuel efficiency. The goal is to understand the factors affecting car prices and build a regression model capable of estimating vehicle prices accurately.

## Dataset

The dataset includes information about Ford vehicles with the following features:

| Feature      | Description                                      |
| ------------ | ------------------------------------------------ |
| model        | Ford vehicle model                               |
| year         | Manufacturing year                               |
| transmission | Transmission type (Manual, Automatic, Semi-Auto) |
| mileage      | Total miles driven                               |
| fuelType     | Fuel type                                        |
| tax          | Annual road tax                                  |
| mpg          | Miles per gallon                                 |
| engineSize   | Engine size (liters)                             |
| price        | Vehicle price (Target Variable)                  |

The dataset is commonly used for regression problems and price prediction tasks.

## Key Insights

* Vehicle age significantly impacts resale value.
* Mileage generally has a negative correlation with price.
* Engine size and fuel efficiency contribute to price variation.
* Newer vehicles tend to maintain higher market value.
