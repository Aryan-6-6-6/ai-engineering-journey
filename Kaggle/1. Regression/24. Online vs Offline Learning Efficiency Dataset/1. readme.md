# 🎓 Online vs Offline Learning Efficiency Prediction using Machine Learning

## 📖 Overview

This project analyzes the **Online vs Offline Learning Efficiency** dataset to predict students' **Exam Scores** using Machine Learning regression models. The workflow includes data exploration, preprocessing, feature transformation, model training, hyperparameter tuning, and performance evaluation.

Multiple regression algorithms were trained and compared using **RandomizedSearchCV** with cross-validation to identify the most accurate model. The models were evaluated using regression metrics, allowing a comprehensive comparison of traditional and ensemble learning techniques.

📓 **Kaggle Notebook:**  
https://www.kaggle.com/code/abacilla/online-vs-offline-learning-efficiency-dataset

---

# 📊 Dataset

The dataset contains **1,000 student records** with information about learning mode, subject, study hours, retention score, focus level, and exam performance. It is designed to analyze how different learning environments influence academic outcomes.

**Target Variable**

- **Exam Score**

> **Note:** The dataset is too large to upload to GitHub, so only the Kaggle dataset link is provided.

# 🔍 Exploratory Data Analysis (EDA)

The notebook performs exploratory analysis to understand student learning patterns and identify relationships between study habits and exam performance.

### Analysis Performed

- Unique value inspection
- Spelling consistency check
- Numerical and categorical feature identification
- Univariate analysis

- Count plots for categorical features

### 📌 Key EDA Insights

### 🔍 Key Findings

- LightGBM achieved the highest cross-validation score among all evaluated models.
- XGBoost delivered performance very close to the best-performing model.
- Ensemble learning methods significantly outperformed the Decision Tree model.
- RandomizedSearchCV effectively optimized model hyperparameters.
- Feature scaling and preprocessing contributed to improved predictive accuracy.
- Study-related numerical features showed strong predictive capability for exam scores.
