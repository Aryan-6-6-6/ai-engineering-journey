# 💰 Financial Sample Data Analysis & Sales Prediction

## 📖 Overview

This project focuses on predicting **Sales** using the Financial Sample dataset through a complete Machine Learning workflow. The notebook covers data understanding, exploratory data analysis (EDA), data cleaning, preprocessing, feature engineering, model training, hyperparameter tuning, and model evaluation.

Multiple regression algorithms were trained and compared using **RandomizedSearchCV** with cross-validation to identify the best-performing model. The final model was evaluated using regression metrics, allowing a comprehensive comparison of traditional and ensemble learning approaches.

# 🔍 Exploratory Data Analysis (EDA)

The notebook performs an extensive exploratory data analysis to understand the dataset structure, identify quality issues, and discover patterns before building Machine Learning models.

### Analysis Performed

- Dataset overview and structure inspection
- Shape and feature analysis
- Missing value analysis
- Duplicate record detection
- Data type inspection
- Descriptive statistical analysis
- Negative profit analysis
- Categorical value inspection
- Unique value analysis
- Spelling consistency checks
- Distribution analysis
- Correlation analysis
- Sales and profit trend visualization
- Country-wise analysis
- Product-wise analysis
- Segment-wise analysis
- Discount impact analysis
- Monthly and yearly sales analysis

### 📌 Key EDA Insights

- Missing values were identified across multiple columns before preprocessing.
- The **Units Sold** column required data type conversion.
- **Month Number** and **Month Name** represented duplicate information.
- Excel serial dates required conversion into proper datetime format.
- The **Sales** column contained unnecessary whitespace.
- The **Discounts** column contained redundant values that required cleaning.
- Date-related features required formatting before model training.
- Negative profit transactions were identified and analyzed separately.
