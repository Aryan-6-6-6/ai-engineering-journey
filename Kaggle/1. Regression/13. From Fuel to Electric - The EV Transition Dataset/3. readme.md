# ⚡ From Fuel to Electric — EV Transition: Monthly Charging Cost Prediction

## Overview

This project predicts a consumer's **monthly EV charging cost** based on demographic, vehicle, and behavioral factors related to the transition from fuel to electric vehicles. It covers data cleaning, EDA, and comparison of 8 regression models tuned with GridSearchCV.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/from-fuel-to-electric-the-ev-transition-dataset

---

## Dataset

Global EV adoption behavior dataset covering demographics, vehicle usage, charging infrastructure access, and EV-related attitudes.

* **Target:** `monthly_charging_cost`
* **Dataset:** https://www.kaggle.com/datasets/aiexplorer77/from-fuel-to-electric-the-ev-transition-dataset

---

## 🧹 Data Cleaning

* No duplicate rows found
* **271 negative values** in `fuel_expense_per_month` were clipped to 0 (a negative fuel expense isn't realistic)
* Imputed missing values: `education_level` (mode), `charging_station_accessibility` and `ev_knowledge_score` (median) — 500 missing each
* Removed **2,996 outlier rows** across financial/distance columns using the IQR method

---

## 🔍 EDA

* **Univariate:** histograms + boxplots for continuous variables (age, income, commute distance, vehicle age, fuel expense, charging cost, etc.), value counts/plots for binary columns (home charging availability, previous EV experience), count plots for categorical columns
* **Bivariate:** correlation heatmap, stacked bar plots (categorical features vs EV adoption likelihood), boxplots (continuous features vs EV adoption likelihood), grouped count plots (binary features vs EV adoption likelihood)
* **Multivariate:** scatter plot (income vs environmental awareness by adoption likelihood), boxplot (income by city type and adoption likelihood), heatmap (avg income by education & city type), violin plot (income by vehicle type and adoption likelihood)

---

## 🛠️ Data Preprocessing

* One-hot encoded categorical columns (`education_level`, `city_type`, `current_vehicle_type`, `ev_adoption_likelihood`)
* Train-test split (80/20, `random_state=42`)
* Standardized non-binary numeric features using `StandardScaler` (fit on train, transformed on test)

---

## 🤖 Model Selection & Tuning

* 5-fold cross-validation (`KFold`, shuffled, `random_state=42`)
* **GridSearchCV** used to tune 8 regression models, scored on R²

| Rank | Model | Best CV R² |
| :--: | :--- | :---: |
| 🥇 | Random Forest Regressor | **0.9992** |
| 2 | Decision Tree Regressor | 0.9988 |
| 3 | Lasso Regression | 0.9256 |
| 4 | ElasticNet Regression | 0.9255 |
| 5 | Bayesian Ridge | 0.9255 |
| 6 | Ridge Regression | 0.9255 |
| 7 | Linear Regression | 0.9255 |
| 8 | KNN Regressor | 0.9039 |

**Best Model: Random Forest Regressor** (`max_depth=20, min_samples_split=5, n_estimators=300`)

---

## 🏆 Results

Test set performance of the best model:

* **MAE:** 0.4845
* **MSE:** 0.4108
* **RMSE:** 0.6410
* **R²:** 0.9993

### 📌 Key Findings

* **Random Forest** and **Decision Tree** (tree-based models) dramatically outperformed all linear models, suggesting strong non-linear relationships in the data
* Linear models (Linear, Ridge, Lasso, ElasticNet, Bayesian Ridge) all clustered tightly around R² ≈ 0.9255, indicating they captured a similar, simpler portion of the signal
* The near-perfect test R² (0.9993) with very low error values shows the engineered features strongly determine monthly charging cost
