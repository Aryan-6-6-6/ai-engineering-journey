# UK Used Car Price Prediction & Analysis

This project provides an end-to-end data processing and exploratory analysis pipeline for the UK Used Car Dataset. It combines data from multiple manufacturers, cleans structural inconsistencies, and prepares the features for predictive regression modeling.

## 📊 Dataset Overview

The pipeline automatically merges and processes car data across several major manufacturers:

* **Brands Included:** Audi, BMW, Ford, Mercedes-Benz, Skoda, Toyota, VW, Vauxhall, and C-Class models.
* **Key Features:** Model, registration year, price, transmission, mileage, fuel type, road tax, mpg, and engine size.

## 🧼 Data Cleaning & Preprocessing

To ensure high model accuracy, the dataset undergoes the following cleaning steps:

1. **Data Ingestion:** Merges separate manufacturer files into a single dataset of 94,327 rows.
2. **Deduplication:** Identifies and removes 1,389 duplicate records.
3. **Outlier Removal:** 
   * Filters out rare or invalid categories (e.g., removing 'Other' transmissions and 'Electric' fuel types to focus on core segments).
   * Filters out unrealistic registration years, restricting data to a realistic range between 2007 and 2025.

* **Language:** Python
