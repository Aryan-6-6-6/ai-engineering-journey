# 🚗 Used Car Price Prediction using Machine Learning

## 📖 Overview

This project focuses on predicting the selling price of used cars using supervised Machine Learning techniques. The workflow covers data exploration, preprocessing, feature engineering, model training, hyperparameter tuning, and performance evaluation to identify the most effective regression model for price prediction.

Multiple regression algorithms were trained and compared using **GridSearchCV** with cross-validation to optimize model performance. The final models were evaluated using regression metrics, allowing a fair comparison between baseline linear models and advanced ensemble-based approaches.

## 📊 Dataset

The project uses a real-world used car dataset containing vehicle specifications and pricing information. The dataset includes various numerical and categorical attributes describing each vehicle, which are used to predict its selling price.

- Checked for missing values.

- Explored the distribution of numerical variables.
- Visualized categorical feature distributions.
- Investigated relationships between important features and the target variable.

- Used visualizations to better understand feature patterns before preprocessing.

## 🏆 Results

The performance of all regression models was evaluated using **GridSearchCV** with cross-validation. After hyperparameter tuning, the models were ranked based on their **Best Cross-Validation R² Score**.

| Rank | Model | Best CV R² Score |
|------|-------|-----------------:|
| 🥇 | XGBoost Regressor | **0.693280** |
| 🥈 | Gradient Boosting Regressor | **0.689113** |
| 🥉 | Random Forest Regressor | **0.682469** |
| 4 | Decision Tree Regressor | **0.615944** |
| 5 | Ridge Regression | **0.597806** |
| 6 | Linear Regression | **0.597806** |
| 7 | Lasso Regression | **0.597804** |
| 8 | Elastic Net Regression | **0.593845** |

---

### 🏅 Best Model Performance

**Best Model:** 🥇 **XGBoost Regressor**

| Metric | Value |
|---------|-------:|
| Mean Absolute Error (MAE) | **0.517590** |
| Root Mean Squared Error (RMSE) | **0.669475** |
| R² Score | **0.694448** |

The tuned XGBoost model achieved the highest cross-validation score while also delivering the strongest performance on the test dataset, making it the most reliable model for predicting used car prices in this project.

### 🔍 Key Findings

- XGBoost Regressor achieved the highest overall performance after hyperparameter tuning.
- Ensemble learning methods consistently outperformed traditional linear regression models.
- GridSearchCV helped optimize model hyperparameters and improve predictive performance.
- Feature preprocessing, including encoding and scaling, prepared the dataset effectively for machine learning algorithms.
- Linear models provided a solid baseline but were less capable of capturing complex relationships within the data.
- Comparing multiple regression algorithms helped identify the most suitable model for the used car price prediction task.
