# Employee Salary Prediction Using Linear Regression

## Overview

This project focuses on predicting employee income using Machine Learning techniques. The dataset contains employee information such as age and years of experience. The objective is to analyze the relationship between these factors and income levels and build a Linear Regression model capable of accurately estimating employee salaries.

## Dataset

The dataset consists of the following features:

| Feature    | Description                       |
| ---------- | --------------------------------- |
| Age        | Age of the employee               |
| Experience | Years of work experience          |
| Income     | Employee income (Target Variable) |

The dataset is commonly used for regression analysis and salary prediction tasks.

## Project Workflow

### 1. Data Loading

* Imported and explored the dataset
* Checked data types and dataset dimensions
* Verified data quality and structure

### 2. Exploratory Data Analysis (EDA)

Performed data visualization to better understand the dataset:

* Histogram analysis to study feature distributions
* Boxplot analysis to identify potential outliers
* Correlation analysis to understand relationships between variables
* Examination of income trends with age and experience

### 3. Data Preprocessing

* Handled data preparation for modeling
* Applied Label Encoding where required
* Applied One-Hot Encoding for categorical features
* Standardized features using StandardScaler
* Split data into training and testing sets

### 4. Model Building

Built a Linear Regression model to predict employee income based on the available features.

### 5. Model Evaluation

Model performance was evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score
* Adjusted R² Score

## Results

The Linear Regression model achieved an **Adjusted R² Score of 0.9322**, indicating that approximately **93.22% of the variance in employee income** is explained by the selected features.

## Key Insights

* Employee income generally increases with experience.
* Age and experience show a positive relationship with earnings.
* Experience is a strong predictor of employee income.
* The Linear Regression model effectively captures the relationship between employee characteristics and salary levels.
