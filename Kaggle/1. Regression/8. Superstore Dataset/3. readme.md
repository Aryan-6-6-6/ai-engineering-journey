# Superstore Sales Prediction Using Machine Learning

## Overview

This project predicts **Sales** using multiple Machine Learning regression models. It demonstrates an end-to-end ML workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, hyperparameter tuning using **GridSearchCV**, model training, and performance comparison to identify the best-performing regression model.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/superstore-dataset#ML

---

## Dataset

The project uses the **Superstore Dataset**, which contains customer, product, order, and shipping information used to predict sales.

**📊 Dataset:** https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## 🏆 Results

Seven regression models were trained and optimized using **GridSearchCV**. Model performance was compared using the **Cross-Validation R² Score**.

| Rank | Model                          | Best CV R² Score |
| :--: | ------------------------------ | :--------------: |
|  🥇  | Gradient Boosting Regressor    |    **0.8600**    |
|   2  | Random Forest Regressor        |      0.8028      |
|   3  | Lasso Regression               |      0.7911      |
|   4  | Ridge Regression               |      0.7898      |
|   5  | ElasticNet Regression          |      0.7898      |
|   6  | Linear Regression              |      0.7893      |
|   7  | Support Vector Regressor (SVR) |      0.7650      |

### Final Model Performance

The **Gradient Boosting Regressor** was selected as the best-performing model and achieved the following performance on the test dataset:

* **RMSE:** 170.39
* **MSE:** 29,031.50
* **R² Score:** 0.4012

### Key Findings

* **Gradient Boosting Regressor** achieved the highest cross-validation performance with an **R² Score of 0.8600**.
* Tree-based ensemble models outperformed traditional linear regression models.
* Hyperparameter tuning using **GridSearchCV** improved model selection and overall predictive performance.
