# 📱 Smartphone Price Prediction using Random Forest

## Overview

This project predicts **smartphone price** based on hardware specs like camera, RAM, CPU score, and connectivity features, using a Random Forest Regressor.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/smartphone-price-model

---

## Dataset

Mobile phone specs dataset with camera, age, RAM, CPU score, SD slot, SIM count, and price.

* **Target:** `price`
* **Dataset:** https://www.kaggle.com/datasets/mussabomair/mobile-phone-prices

---

## 🔍 EDA

* Checked shape, dtypes, stats, and duplicates (none found, no missing values)
* Univariate: histograms for camera, age, RAM, CPU score, price; count plots for SD slot and SIM count
* Correlation heatmap across all numeric features

### 📌 Key Insights

* Dataset was already clean — no preprocessing/cleaning step was needed before EDA
* Price is fairly spread across a wide range (~8K to ~70K)
* Camera, RAM, and CPU score showed visible relationships with price in the correlation heatmap

---

## 🤖 Model Used

* **Random Forest Regressor** (`n_estimators=200`, `random_state=42`)
* Trained on provided `train.csv`, evaluated on provided `test.csv`

---

## 🏆 Results

| Metric | Score |
| :--- | :---: |
| MAE | 5656.81 |
| MSE | 44,265,254.25 |
| RMSE | 6653.21 |
| R² | 0.845 |

* **Accuracy within ±10% tolerance:** 40.00%
* **Exact-match accuracy:** 0.00%

### 📌 Key Findings

* The model explains ~84.5% of the variance in price (R² = 0.845), indicating a reasonably strong fit
* Despite a good R², only 40% of predictions fall within 10% of the actual price — showing that **R² alone can overstate real-world prediction precision**
* Exact-match accuracy is expectedly 0%, since price is a continuous variable
