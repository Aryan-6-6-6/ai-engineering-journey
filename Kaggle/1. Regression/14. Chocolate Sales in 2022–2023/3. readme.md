# 🍫 Chocolate Sales Analysis & Shipment Prediction

A comprehensive Machine Learning regression project that analyzes chocolate sales data, performs exploratory data analysis, engineers meaningful features, and compares multiple regression models to accurately predict the number of chocolate boxes shipped.

---
📓 **Kaggle Notebook:** https://www.kaggle.com/code/abacilla/chocolate-sales-in-2022-2023

# 📖 Overview

This project focuses on predicting the **number of chocolate boxes shipped** using historical sales records. The notebook demonstrates a complete end-to-end machine learning workflow, beginning with data cleaning and exploratory data analysis, followed by feature engineering, preprocessing, model training, hyperparameter tuning, and performance evaluation.

The project is a **Supervised Machine Learning Regression** task whose objective is to build an accurate model capable of predicting shipment quantities from available sales-related features.

# 📊 Dataset

**Dataset:** Chocolate Sales (2022–2023)

**Dataset Purpose**

The dataset contains historical chocolate sales transactions collected during 2022–2023. It includes information related to products, customers, locations, sales amount, shipment details, and transaction dates.

**Target Variable**

* **Boxes Shipped**

The goal is to predict the number of boxes shipped for each transaction.

## 📌 Key EDA Insights

The notebook identifies several important observations:

* Some columns had incorrect data types and required conversion before modeling.
* Missing values were present in both numerical and date columns.
* The **Amount** column initially contained object values and additional missing values after datatype conversion.
* Negative values were found in the **Boxes Shipped** column and were corrected during data cleaning because shipment quantities cannot be negative.
* Numerical variables showed noticeable skewness.
* Several numerical features contained outliers as observed through boxplots.
* Categorical feature distributions were explored to understand class frequencies.
* Log transformation significantly reduced skewness in numerical features before model training.

---

# ⚙️ Data Transformation & Preprocessing

The preprocessing pipeline was designed based on observations obtained during EDA.

### Data Cleaning

* Removed redundant columns.
* Filled missing numerical values.
* Filled missing date values.
* Corrected incorrect data types.
* Replaced invalid negative shipment values.
* Filled additional missing values created after datatype conversion.

### Feature Engineering

New features were created to improve predictive performance and better represent temporal and transactional information.

### Log Transformation

EDA revealed skewed numerical distributions. Therefore, log transformation was applied to reduce skewness and improve model learning.

### One-Hot Encoding

Categorical variables were transformed into numerical representations using One-Hot Encoding so regression algorithms could process them effectively.

### Standard Scaling

Feature scaling was applied after train-test splitting to normalize numerical features and improve model performance for algorithms sensitive to feature magnitude.

### Train-Test Split

The dataset was divided into training and testing subsets before model development.

## 🔍 Key Findings

* Decision Tree achieved the highest predictive performance among all tested models.
* Gradient boosting models (XGBoost and LightGBM) also delivered excellent accuracy, closely matching the Decision Tree.
* Linear models performed well but were significantly outperformed by tree-based approaches, suggesting the presence of non-linear relationships in the data.

* A structured preprocessing pipeline contributed to achieving highly accurate shipment predictions.
