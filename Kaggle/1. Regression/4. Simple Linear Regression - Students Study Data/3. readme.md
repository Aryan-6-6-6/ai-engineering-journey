# Students Study Data Analysis and Marks Prediction Using Linear Regression

## Overview

This project focuses on predicting student marks using Machine Learning techniques. The dataset contains information about the number of hours studied by students and their corresponding marks. The objective is to analyze the relationship between study hours and academic performance and build a Linear Regression model capable of accurately predicting student marks.

## Dataset

The dataset consists of the following features:

| Feature       | Description                                     |
| ------------- | ----------------------------------------------- |
| Hours_Studied | Number of hours studied by the student          |
| Marks         | Marks obtained by the student (Target Variable) |

The dataset is commonly used for simple linear regression analysis and educational performance prediction tasks.

## Project Workflow

### 1. Data Loading

* Imported and explored the dataset
* Checked data types and dataset dimensions
* Verified data quality and structure
* Identified missing values and duplicate records

### 2. Exploratory Data Analysis (EDA)

Performed data visualization to better understand the dataset:

#### Univariate Analysis

* Histogram analysis to study the distribution of study hours
* Histogram analysis to examine the distribution of marks
* Boxplot analysis to identify potential outliers
* Summary statistics analysis using descriptive measures

#### Bivariate Analysis

* Scatter plot analysis to understand the relationship between study hours and marks
* Correlation analysis to measure the strength of association between variables

### 3. Data Preprocessing

* Selected input feature (`Hours_Studied`) and target variable (`Marks`)
* Split the dataset into training and testing sets using `train_test_split`
* Maintained proper separation of training and testing data to avoid data leakage
* Prepared the dataset for model training and evaluation

### 4. Model Building

Built a Simple Linear Regression model to predict student marks based on the number of hours studied.

### 5. Model Evaluation

Model performance was evaluated using:

* Mean Squared Error (MSE)
* R² Score

Metrics were calculated using:

```python
from sklearn.metrics import mean_squared_error, r2_score
```

## Results

The Linear Regression model achieved the following performance:

* **Mean Squared Error (MSE): 13.2854**
* **R² Score: 0.9336**

The model explains approximately **93.36% of the variance in student marks**, indicating a strong linear relationship between study hours and academic performance.

## Key Insights

* Students who study for more hours generally achieve higher marks.
* A strong positive correlation exists between study hours and marks.
* Study time is a significant predictor of academic performance.
* The Linear Regression model effectively captures the relationship between hours studied and marks obtained.
