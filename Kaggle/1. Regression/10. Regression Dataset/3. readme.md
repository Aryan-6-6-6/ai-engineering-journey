# 🏆 Results

Five regression models were trained and evaluated using **MAE**, **MSE**, **RMSE**, and **R² Score**.

| Rank | Model                    |   MAE |  RMSE |  R² Score  |
| :--: | ------------------------ | ----: | ----: | :--------: |
|  🥇  | **Ridge Regression**     | 16.55 | 19.30 | **0.0772** |
|  🥈  | Linear Regression        | 16.53 | 19.31 |   0.0769   |
|  🥉  | Support Vector Regressor | 17.33 | 19.98 |   0.0117   |
|   4  | Lasso Regression         | 17.41 | 20.09 |  -0.00004  |
|   5  | Elastic Net              | 17.41 | 20.09 |  -0.00004  |

### 🔍 Key Findings

* 🏆 **Ridge Regression** achieved the highest **R² Score (0.0772)**, making it the best-performing model on this dataset.
* 📉 Linear Regression produced nearly identical performance, indicating limited benefits from regularization on the current feature set.
* ⚠️ The relatively low R² values suggest that the available features explain only a small portion of the target variable's variance, leaving room for improved feature engineering and model optimization.
