# 🤖 Impact of AI on Students: Performance Prediction Using Machine Learning

## 📖 Overview

This project predicts students' **academic performance** by analyzing how various AI-related learning factors influence outcomes. It demonstrates a complete Machine Learning workflow, including data exploration, preprocessing, feature engineering, hyperparameter tuning, and regression model comparison to identify the best-performing algorithm.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/impact-of-ai-on-students#6.-Machine-Learning-and-Hyperparameter-Tuning

---

# 📊 Dataset

The project uses the **AI Impact on Students Dataset**, which contains demographic, academic, and AI usage-related attributes to predict student performance.

**📂 Dataset:** https://www.kaggle.com/datasets/laveshjadon/ai-impact-on-students/data

---

# 🔍 Exploratory Data Analysis (EDA)

A detailed EDA was performed to understand the dataset, identify patterns, and prepare the data for model training.

### Analysis Performed

* Dataset overview and descriptive statistics
* Missing value and duplicate record analysis
* Univariate analysis using histograms and boxplots
* Distribution analysis of numerical features
* Categorical feature analysis
* Correlation heatmap
* Relationship analysis between input features and the target variable

### 📌 Key EDA Insights

* The dataset contained a mix of numerical and categorical features that required preprocessing.
* Correlation analysis highlighted the features that contributed most to predicting student performance.
* Feature distributions and outlier analysis guided preprocessing decisions before model training.
* EDA provided a better understanding of how AI-related factors influence academic outcomes.

---

# ⚙️ Data Transformation & Preprocessing

Based on the EDA findings, the following preprocessing steps were performed:

* Handled missing values and duplicate records
* Encoded categorical variables
* Applied feature scaling where required
* Performed Train-Test Split
* Optimized model hyperparameters using **RandomizedSearchCV**
* Evaluated models using **5-Fold Cross Validation**

---

# 🏆 Results

Seven regression models were optimized and evaluated using **Cross-Validation R² Score**.

| Rank | Model             | Best CV R² Score |
| :--: | ----------------- | :--------------: |
|  🥇  | **LightGBM**      |    **0.9147**    |
|  🥈  | XGBoost           |      0.9124      |
|  🥉  | Ridge Regression  |      0.8969      |
|   4  | Linear Regression |      0.8969      |
|   5  | ElasticNet        |      0.8968      |
|   6  | Lasso Regression  |      0.8959      |
|   7  | Decision Tree     |      0.8808      |

### 🏅 Best Model Performance

The **LightGBM Regressor** achieved the best overall performance after hyperparameter tuning.

| Metric       |      Value |
| ------------ | ---------: |
| **MAE**      | **0.1124** |
| **RMSE**     | **0.1427** |
| **R² Score** | **0.9157** |

### 🔍 Key Findings

* 🥇 **LightGBM** achieved the highest Cross-Validation **R² Score (0.9147)**, making it the best-performing regression model.
* 🚀 **XGBoost** delivered competitive performance, finishing just behind LightGBM.
* 📈 Traditional linear models (Linear, Ridge, Lasso, and ElasticNet) produced consistent results but were outperformed by ensemble boosting techniques.
* 🎯 The final LightGBM model explained approximately **91.6%** of the variance in student performance, demonstrating strong predictive capability.
