# 🎓 Student Placement Prediction Using Machine Learning

## 📖 Overview

This project predicts **student placement outcomes** using multiple Machine Learning regression models. It follows a complete end-to-end Machine Learning workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, data preprocessing, **Principal Component Analysis (PCA)**, hyperparameter tuning using **RandomizedSearchCV**, and model comparison to identify the best-performing regression model.

**📓 Kaggle Notebook:**
https://www.kaggle.com/code/abacilla/student-placement-prediction-dataset-2026

---

# 📊 Dataset

The project uses the **Student Placement Prediction Dataset**, which contains academic, skill-based, and performance-related information that can influence a student's placement outcome.

The objective is to predict the **placement score** based on various student attributes and compare multiple Machine Learning algorithms to identify the most accurate model.

**🎯 Target Variable:** `Placement Score`

**📂 Dataset:**
https://www.kaggle.com/code/abacilla/student-placement-prediction-dataset-2026

# 🔍 Exploratory Data Analysis (EDA)

A comprehensive Exploratory Data Analysis (EDA) was performed to understand the dataset, identify data quality issues, and discover relationships between student characteristics and placement scores before model development.

### Analysis Performed

* Dataset overview and descriptive statistics
* Missing value analysis
* Duplicate record detection
* Univariate analysis
* Distribution analysis of numerical features
* Correlation heatmap
* Outlier analysis
* Relationship analysis between features and placement score

### 📌 Key EDA Insights

* The dataset contained a combination of numerical and categorical features requiring preprocessing before model training.
* Correlation analysis identified the variables that contributed most to predicting placement scores.
* Feature distributions and outlier detection improved data quality before modeling.
* EDA provided valuable insights for feature selection and dimensionality reduction.

---

# ⚙️ Data Transformation & Preprocessing

Based on the EDA findings, the following preprocessing steps were performed:

* Removed unnecessary columns
* Handled missing values and duplicate records
* Encoded categorical variables
* Applied feature scaling
* Reduced dimensionality using **Principal Component Analysis (PCA)**
* Split the dataset into training and testing sets
* Optimized model hyperparameters using **RandomizedSearchCV**
* Evaluated models using **5-Fold Cross Validation**

# 🏆 Results

Eight regression models were optimized using **RandomizedSearchCV** and compared using the **Cross-Validation R² Score**.

| Rank | Model                   | Best CV R² Score |
| :--: | ----------------------- | :--------------: |
|  🥇  | **LightGBM Regressor**  |   **0.986405**   |
|  🥈  | Random Forest Regressor |   **0.984784**   |
|  🥉  | XGBoost Regressor       |   **0.979198**   |
|   4  | Decision Tree Regressor |   **0.978519**   |
|   5  | Ridge Regression        |   **0.798445**   |
|   6  | Linear Regression       |   **0.798445**   |
|   7  | Lasso Regression        |   **0.798444**   |
|   8  | ElasticNet Regression   |   **0.798444**   |

### 🏅 Best Model Performance

The **LightGBM Regressor** achieved the best overall performance after hyperparameter tuning.

| Metric       |      Value |
| ------------ | ---------: |
| **MAE**      | **0.4957** |
| **RMSE**     | **0.7990** |
| **R² Score** | **0.9859** |

### 🔍 Key Findings

* 🥇 **LightGBM Regressor** achieved the highest **Cross-Validation R² Score (0.9864)**, making it the best-performing model.
* 🌲 Tree-based ensemble models (**LightGBM**, **Random Forest**, and **XGBoost**) significantly outperformed traditional linear regression models.
* 📈 Applying **PCA** helped reduce dimensionality while preserving the most informative features for model training.
* ⚙️ Hyperparameter tuning using **RandomizedSearchCV** further improved model performance and generalization.
* 🎯 The final model achieved an excellent **R² Score of 0.9859**, indicating highly accurate placement score predictions.
