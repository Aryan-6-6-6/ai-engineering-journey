# 🏥 US Health Insurance Charges Prediction

## Overview

This project predicts **medical insurance charges** based on demographic and health factors (age, BMI, smoking status, region, etc.), comparing 9 regression models tuned with GridSearchCV.

**📓 Kaggle Notebook:** https://www.kaggle.com/code/abacilla/us-health-insurance-dataset

---

## Dataset

US health insurance dataset with age, sex, BMI, children, smoking status, region, and charges.

* **Target:** `charges`
* **Dataset:** https://www.kaggle.com/datasets/teertha/ushealthinsurancedataset

---

## 🧹 Data Cleaning

* Found and removed **1 duplicate row**
* Removed **BMI outliers** using the IQR method
* Charges outliers were checked but intentionally left untouched

---

## 🔍 EDA

* **Univariate:** histograms for age and BMI, count plots for sex/smoker/region, pie chart for children, boxplot for charges
* **Bivariate:** regplots (age vs BMI, children vs charges), boxplot (smoker vs charges), violin plot (region vs charges), bar plots (region vs BMI, region vs charges, region/sex vs smoker)
* **Multivariate:** correlation heatmap across numeric features

### 📌 Key Insights

* Ages 18–22 form the largest demographic in the dataset
* Gender is almost equally distributed
* BMI roughly follows a normal (bell-curve) distribution
* Having 4–5 children is rare, but not a data quality issue
* Majority of beneficiaries are non-smokers
* Regions are nearly uniformly distributed
* Smokers have noticeably higher charges than non-smokers
* More children is associated with higher charges
* Age and BMI show a weak positive relationship

---

## 🛠️ Data Preprocessing

* One-hot encoded categorical columns (`sex`, `smoker`, `region`)
* Train-test split (80/20, `random_state=42`)
* Standardized non-binary numeric features using `StandardScaler` (fit on train, transformed on test)

---

## 🤖 Model Selection & Tuning

* 5-fold cross-validation (`KFold`, shuffled, `random_state=42`)
* **GridSearchCV** used to tune 9 regression models, scored on R²

| Rank | Model | Best CV R² |
| :--: | :--- | :---: |
| 🥇 | Gradient Boosting Regressor | **0.8548** |
| 2 | Random Forest Regressor | 0.8512 |
| 3 | Decision Tree Regressor | 0.8362 |
| 4 | Lasso | 0.7373 |
| 5 | ElasticNet | 0.7363 |
| 6 | Ridge | 0.7362 |
| 7 | Linear Regression | 0.7361 |
| 8 | KNeighbors Regressor | 0.7045 |
| 9 | SVR | -0.0448 |

**Best Model: Gradient Boosting Regressor** (`learning_rate=0.01, n_estimators=500`)

---

## 🏆 Results

Test set performance of the best model:

* **RMSE:** 4605.32
* **MSE:** 21,208,968.29
* **R²:** 0.8474

### 📌 Key Findings

* **Gradient Boosting Regressor** achieved the best cross-validation and test performance
* Tree-based ensemble models (Gradient Boosting, Random Forest, Decision Tree) clearly outperformed linear models
* **SVR performed worst**, with a negative CV R², indicating it failed to capture the underlying pattern with default/tuned settings
* Linear models (Linear, Lasso, Ridge, ElasticNet) clustered closely around R² ≈ 0.74, suggesting the relationship isn't fully linear
